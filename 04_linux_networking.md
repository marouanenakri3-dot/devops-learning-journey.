# 🌐 Day 4: Linux Networking & Remote Connections

## Key Concepts Learned:
- **IP & Ports**: Identifying network interfaces and port availability.
- **SSH Protocol**: Secure Remote Login using key-based authentication.

## Commands Practiced:
- `ip a` : Show IP addresses and network interfaces.
- `ping -c 4 <host>` : Send 4 ICMP echo requests to test connection.
- `curl -I <url>` : Fetch HTTP header response from a web server.
- `ssh user@host` : Securely connect to a remote server.
