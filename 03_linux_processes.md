# 🐧 Day 3: Linux Process Management & System Monitoring

## Key Concepts Learned:
- **System Resource Monitoring**: Tracking CPU, RAM, and system load in real-time.
- **Process Lifecycle**: Managing active processes using PIDs and signal controls.

## Commands Practiced:
- `free -m` : Check free and used RAM memory in MB.
- `top` / `htop` : Display active Linux processes and resource usage.
- `ps aux` : View all running processes on the system.
- `command &` : Run a command in the background.
- `kill <PID>` : Terminate a process safely using its ID.
