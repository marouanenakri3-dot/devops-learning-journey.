# 🐧 Day 2: Linux Permissions & User Management

## Key Concepts Learned:
- **Permissions Structure**: `r` (Read = 4), `w` (Write = 2), `x` (Execute = 1).
- **Owner / Group / Others**: How Linux isolates access across different users.

## Commands Practiced:
- `ls -l` : Display detailed file information including permissions.
- `chmod +x <file>` : Make a script executable.
- `chmod 755 <file>` : Full access for owner, read/execute for others.
- `sudo` : Execute commands with superuser (root) privileges.
