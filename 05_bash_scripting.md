# 📜 Day 5: Introduction to Bash Scripting & Automation

## Key Concepts Learned:
- **Shebang (`#!/bin/bash`)**: Specifies the interpreter for execution.
- **Variables & Automation**: Storing system metrics and executing commands conditionally.
- **Script Execution**: Granting execute permissions using `chmod +x`.

## Commands & Scripts Practiced:
- `chmod +x script.sh` : Make script executable.
- `./script.sh` : Run script in current directory.
- Created `05_system_health.sh` to check system RAM and network status automatically.
